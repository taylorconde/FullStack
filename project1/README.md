This branch contains the Boilerplate who's used since the 18 Module

It contains: 
Webpack
Babel
core-js@3
regenerator-runtime

Structure 
project/
├── dist/                # Arquivos gerados automaticamente pelo Webpack
│   └── index.html       # Página servida pelo Webpack Dev Server
├── src/                 # Código-fonte do projeto
│   ├── index.js         # Ponto de entrada principal
│   ├── se_necessario.js # Outro ponto de entrada
├── webpack.config.js    # Configuração do Webpack
├── package.json         # Configurações do projeto e dependências
├── .babelrc             # Configuração do Babel
